# PS Randbats Assistant
<!-- impeccable:product-schema 1 -->
## Platform
web
## Purpose and users
Inferred from the existing implementation: a browser extension for Pokémon Showdown players in Gen 9 Random Battles. It estimates move damage and narrows possible opposing sets using battle revelations.
## Constraints
Preserve outgoing damage on move hover, incoming threats, known information, possible and eliminated sets, and collapse controls. Calculations and bundled set data run locally. Predictions must be visibly distinct from observed facts.
## Brand commitments
User requested a very minimalist, abstract whiteboard UI and public release preparation.
## Open decisions
Chrome Web Store is the working release target. Publisher identity, support URL, and hosted privacy URL remain publisher-owned decisions.
