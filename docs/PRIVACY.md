# Privacy policy — PS Randbats Assistant

Effective September 14, 2026.

PS Randbats Assistant processes Gen 9 Random Battle messages on play.pokemonshowdown.com to display damage estimates and possible opposing sets. This includes the player's own team information supplied by Showdown and publicly revealed opponent information.

Processing happens locally in your browser. Battle state is held temporarily in memory. The extension does not transmit this information to its developer or third parties, store battle histories, use analytics, show advertisements, or sell data. It does not request access to other websites. No extension account is required.

The extension uses bundled code and Pokémon set data; it does not download executable code. Pokémon Showdown itself is a separate service with its own privacy practices.

Closing or reloading the page clears in-memory state. Disabling or uninstalling the extension stops its processing. For questions, use the developer contact listed on the Chrome Web Store listing.
